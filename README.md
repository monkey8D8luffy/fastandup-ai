## 🎯 The Problem & Solution
Modern wellness consumers face cognitive overload when navigating complex D2C nutrition catalogs. Faced with highly scientific terms (L-Arginine, hypotonic solutions, BCAAs), the "everyday athlete" experiences choice paralysis, leading to high bounce rates and abandoned carts.

**Fast&Up Pro** solves this by transitioning the consumer journey from *searching a static catalog* to *consulting a digital expert*. By asking 3 highly targeted questions, the AI diagnoses the user's exact needs and recommends the perfect Fast&Up product.

---

## ✨ Key Features

*   **📱 WhatsApp-Style UI/UX:** A highly intuitive, mobile-first interface designed to eliminate technical intimidation and build consumer trust.
*   **🧠 Enterprise-Grade AI Inference:** Powered by **Groq's LPU** and Meta's massive **Llama-3.3-70B** model for lightning-fast, highly empathetic, and professional nutritional advice.
*   **🛡️ Strict Brand Guardrails:** The LLM is mathematically prompt-engineered to *only* recommend Fast&Up products and completely ignore competitor brands.
*   **⚡ Zero-Token FAQ Router:** A built-in, instant-access accordion containing 30 localized customer service queries, saving massive API operational costs.
*   **🔒 Constrained Diagnostic Flow:** Uses a 2x2 interactive button grid to capture clean user data (Goal → Pain Point → Diet) and prevent prompt injection attacks.
